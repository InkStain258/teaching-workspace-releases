一条流水线，从单元到讲评

不是把功能堆在一起：导入的单元结构会一路带着教材、教参、任务与题目走，任何一页都能回到出处。

单元结构导入

粘一份结构化文本或 JSON，自动拆成单元、课文/教学内容、任务与目标；不消耗 AI 额度。

备课中心

教参编写意图、内容解读、教学建议并排看；写教案时引用原文不跑题。

题库与组卷

按篇目、题型、难度筛题，组卷篮随取随放，导出试卷与答案，页边距与字号可控。

学情与讲评

录入得分即出得分率与薄弱点，讲评课按错题排优先级，不必再翻表格。

记忆与复习

名句默写、实词、常识按 0/1/3/7 天排队；闪卡与记忆模块共用一份数据。

插件与脚本

插件只拿宿主 API，不给系统权限；自己写的脚本可以读题库、加页面。

三种外观

浅色、纸本、深色。纸本是横格纸 + 装订线的哑光样式，适合长时间读写。

软件内更新

读公开清单、下载安装包、校验 SHA256 后静默升级，数据原地保留。

离线优先

桌面版把前端全部打进 exe，运行不依赖服务器；局域网也不影响上课。

下载

Windows 10/11 桌面版。安装程序会装到你自己选的目录，数据在安装目录下的 data/。
