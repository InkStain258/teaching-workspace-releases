把你的 AI 客户端接到工作台上

备题达内置一台 MCP 服务器。你的 AI 客户端连上来，就能直接读题库、查篇目、调记忆，不必再复制粘贴。

读全学科版文档 读高中语文版文档 各模块的产品文档 · 含 11 类客户端接入与排错
01

令牌鉴权

每次安装生成一串随机令牌，客户端必须带上才能连。令牌只存在本机配置里，可随时重置，旧的立即失效。

02

写操作你说了算

默认只读。AI 想往记忆里加卡片、往题库里落题，先在窗口里出一张待确认卡片，你点了「执行」才真正写入。

03

不出本机

只监听 127.0.0.1，局域网和外网都连不进来。没有云端中转，没有账号体系，断网也能用。

四步接通

  1. 打开「设置 → MCP」服务随应用启动，状态标签显示「服务运行中」。
  2. 复制带令牌的地址形如 http://127.0.0.1:47321/mcp?token=…，面板上一键复制。
  3. 粘进你客户端的配置Claude Desktop 改 claude_desktop_config.json，Cursor 改 ~/.cursor/mcp.json，其余见教程。
  4. 回面板看「N 个客户端在线」连上后会列出客户端名字、调用次数和最近调用的工具。
claude_desktop_config.jsonJSON
{
  "mcpServers": {
    "petita": {
      "type": "http",
      "url": "http://127.0.0.1:47321/mcp?token=你的令牌"
    }
  }
}
