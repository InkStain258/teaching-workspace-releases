一、MCP 是什么，跟「配个 API Key」有什么不一样

1.1 一句话

API Key 模式是「你把题目贴给 AI，AI 把结果贴回来」。 MCP 模式是「AI 自己伸手进你的题库里翻、挑、改」。

区别在于谁动手：

API Key（现在的做法） MCP（本教程）
谁知道你的题库有什么 AI 只能看到你贴进对话框的那部分 AI 可以自己检索全部
找十道「二次函数·中等难度」的题 你得先自己搜、再复制、再粘贴 AI 自己调 bank_search 拿到
改完的结果 你手动复制回软件 AI 直接写进去
需要联网吗 需要（要调云端接口） 不需要（AI 客户端在你本机，数据也在本机）
需要 API Key 吗 需要 不需要（省掉这笔钱）
数据出本机吗 出（发给模型厂商） 只发给 AI 客户端，备题达本身不联网

1.2 为什么「不需要 API Key」

因为 MCP 用的是你电脑上已经登录好的 AI 客户端。Claude Desktop 用你订阅的额度，Cursor 用你自己的 key，本地跑的模型（Ollama、LM Studio）根本不花钱——备题达这边只是把数据递出去，不管计费。

1.3 一个关键前提

备题达必须开着。 你的题库、教案、记忆卡都存在应用里，MCP 本身不存数据，它只是「转接台」。应用关着的时候，AI 调用工具会明确收到「请先打开备题达」，不会假装成功。

二、开启 MCP

2.1 三步

  1. 打开备题达桌面版（应用会自动启动 MCP 服务，不需要手动开）
  2. 进入「设置 → MCP」
  3. 看到这样一排状态就说明开着：
[服务运行中] [页面已连上] [23 个工具]

连接地址（含令牌）  http://127.0.0.1:47321/mcp?token=915eb38a…   [复制]
仅地址              http://127.0.0.1:47321/mcp                  [复制]
令牌                915eb38a3f7bac6d…                            [复制]

点「复制」拿到带令牌的地址，粘到你的 AI 客户端里就行（各客户端的填法见第三章）。

2.1.1 看谁连着

面板顶部那一排标签就是实时状态，每 3 秒自动刷新：

[服务运行中] [页面已连上] [23 个工具] [2 个客户端在线]

● claude-ai     12 次 · 刚刚
● Cursor        刚刚
最近调用：bank_stats（刚刚）
  • 服务运行中 —— 本地端口在监听
  • 页面已连上 —— 应用窗口活着，能真的执行工具
  • N 个客户端在线 —— 60 秒内有过请求的客户端数
  • 下面每行是一个客户端：名字、累计调用次数、最后活动时间。名字来自客户端握手时上报的 clientInfo.name，拿不到时退回它的 User-Agent
  • 最近调用 —— 上一次被调用的工具名和时间

这排状态是判断「到底通没通」最快的地方：客户端连上后，这里应该多出一行它的名字。如果客户端显示已连接但这里没有记录，说明它连的是别的端口。

面板下方还有三块：

区块 作用
端口 改监听端口，保存后重启应用生效
写操作 「允许 AI 直接写入」开关，见 §2.3
安全 / 自检 重新生成令牌、一键测试连接是否正常

2.2 三个概念

名词 含义 要改吗
地址 本地端口，默认 47321。AI 客户端往这里发请求 一般不用
令牌 32 位随机串。相当于密码，防止你电脑上别的程序乱调 不用改，但要复制
写操作 开关。关着时 AI 只能「提案」，你点执行才生效 建议先关着

2.3 关于「写操作」这个开关

关着（默认） —— AI 想加题、加日程、加卡片时，备题达会弹出一张卡片：

┌────────────────────────────────────┐
│ 把 10 道题加进组卷篮          共 45 分 │
│ · 选择题 5分  已知函数 f(x)=...      │
│ · 选择题 5分  若 a>b>0，则...        │
│                          [执行] [取消] │
└────────────────────────────────────┘

你点「执行」才真的写进去。推荐先用这个，用熟了再考虑打开。

打开 —— AI 调什么就执行什么（仍然会记撤销，可以 Ctrl+Z 回退）。适合你在旁边盯着、批量处理的时候。

读操作（搜题、看教案、查进度）不受这个开关影响，永远是直接执行。

2.4 端口被占用怎么办

如果 47321 被别的程序占了，应用会自动换一个端口。以设置页显示的为准。要固定成别的端口：设置 → MCP → 端口，改完重启应用生效。

三、接各种 AI 客户端

先说明两类接法，看到配置项再对号入座：

类型 长什么样 怎么填
A. 支持 HTTP 的客户端 有「Remote MCP」「HTTP」「SSE」「URL」字样 直接填 http://127.0.0.1:47321/mcp?token=你的令牌
B. 只支持命令行的客户端 只能填 command + args 见 §3.9 的桥接方案

令牌怎么传：?token=xxx 放在地址里最省事。有些客户端支持自定义请求头，那就用 Authorization: Bearer 你的令牌。

3.1 Claude Desktop（Windows / macOS）

配置文件位置：

  • Windows：%APPDATA%\Claude\claude_desktop_config.json
  • macOS：~/Library/Application Support/Claude/claude_desktop_config.json

如果文件不存在就新建，内容：

{
  "mcpServers": {
    "petita": {
      "url": "http://127.0.0.1:47321/mcp?token=你的令牌"
    }
  }
}

改完完全退出 Claude Desktop（右键托盘图标 → Quit，不是关窗口），再打开。

验证：对话里问「用 petita 看看我的题库有多少题」。它应该会调 bank_stats。

旧版 Claude Desktop 不支持 url 字段，只认 command。那就用 §3.9 的桥接。

3.2 Cursor

Ctrl+Shift+P → 输入 MCP → 选 Cursor Settings: MCP → Add new global MCP server。

它打开 ~/.cursor/mcp.json，填：

{
  "mcpServers": {
    "petita": {
      "url": "http://127.0.0.1:47321/mcp?token=你的令牌"
    }
  }
}

保存后 Cursor 会自动连。MCP 面板里 petita 应该亮绿点，显示 23 个工具。

3.3 VS Code（GitHub Copilot Chat）

要求：VS Code 1.102+，装了 Copilot 扩展并登录。

Ctrl+Shift+P → MCP: Add Server → 选 HTTP → 粘贴：

http://127.0.0.1:47321/mcp?token=你的令牌

名字填 petita，作用域选 Global。

或者直接编辑 settings.json：

{
  "mcp": {
    "servers": {
      "petita": {
        "type": "http",
        "url": "http://127.0.0.1:47321/mcp?token=你的令牌"
      }
    }
  }
}

用的时候：Copilot Chat 里切到 Agent 模式，点输入框下的工具图标，勾上 petita。

3.4 Claude Code（命令行）

claude mcp add --transport http petita "http://127.0.0.1:47321/mcp?token=你的令牌"

加 --scope user 让它对所有项目生效：

claude mcp add --transport http --scope user petita "http://127.0.0.1:47321/mcp?token=你的令牌"

验证：

claude mcp list

应该看到 petita: ... ✓ Connected。

3.5 Cherry Studio

设置 → MCP 服务器 → 添加 → 类型选 可流式传输的 HTTP（streamableHttp）：

字段 填什么
名称 petita
URL http://127.0.0.1:47321/mcp?token=你的令牌

保存后点「检测」，看到 23 个工具就对了。

3.6 Cline（VS Code 扩展）

侧边栏 Cline → 右上角 ⚙️ → MCP Servers → Configure MCP Servers，打开 cline_mcp_settings.json：

{
  "mcpServers": {
    "petita": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:47321/mcp?token=你的令牌",
      "autoApprove": ["bank_search", "question_get", "bank_stats"]
    }
  }
}

autoApprove 可以只放读工具，写工具留着手动批。

3.7 Continue（VS Code / JetBrains）

~/.continue/config.yaml 里加：

mcpServers:
  - name: petita
    type: streamable-http
    url: http://127.0.0.1:47321/mcp?token=你的令牌

3.8 Open WebUI / LibreChat / 其他自建平台

这类平台多半支持「OpenAPI 工具」或「MCP 服务地址」，填上面那个 URL 即可。如果它只认 header，就用：

Authorization: Bearer 你的令牌

3.9 只支持命令行的客户端：用桥接

有些客户端（旧版 Claude Desktop、某些 agent 框架）只能填 command，不能填 URL。这时用一个转发脚本。

第 1 步：确认装了 Node.js

node --version

没有就去 https://nodejs.org 装 LTS 版。

第 2 步：把下面的脚本存成 petita-mcp-bridge.js，放在你顺手的位置（比如 C:\Users\你的用户名\petita-mcp-bridge.js）：

#!/usr/bin/env node
// 把 stdio 上的 MCP 请求转发给备题达的本地 HTTP 服务
const URL_BASE = process.env.PETITA_MCP_URL || "http://127.0.0.1:47321/mcp";
const TOKEN = process.env.PETITA_MCP_TOKEN || "";

const url = TOKEN ? `${URL_BASE}?token=${TOKEN}` : URL_BASE;
let buf = "";

process.stdin.setEncoding("utf8");
process.stdin.on("data", (chunk) => {
  buf += chunk;
  let idx;
  while ((idx = buf.indexOf("\n")) >= 0) {
    const line = buf.slice(0, idx).trim();
    buf = buf.slice(idx + 1);
    if (!line) continue;
    forward(line);
  }
});

async function forward(line) {
  try {
    const res = await fetch(url, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Accept": "application/json, text/event-stream",
      },
      body: line,
    });
    const text = await res.text();
    // MCP 的 stdio 传输是一行一个 JSON
    const payload = text.trim();
    if (payload) process.stdout.write(payload + "\n");
  } catch (e) {
    // 通知类消息没有 id，不能回错误帧
    let id = null;
    try { id = JSON.parse(line).id ?? null; } catch (_) {}
    if (id !== null) {
      process.stdout.write(JSON.stringify({
        jsonrpc: "2.0", id,
        error: { code: -32000, message: "连不上备题达：" + String(e) }
      }) + "\n");
    }
  }
}

第 3 步：客户端配置里这么填

{
  "mcpServers": {
    "petita": {
      "command": "node",
      "args": ["C:\\Users\\你的用户名\\petita-mcp-bridge.js"],
      "env": {
        "PETITA_MCP_URL": "http://127.0.0.1:47321/mcp",
        "PETITA_MCP_TOKEN": "你的令牌"
      }
    }
  }
}

3.10 自己写 agent：直接打 HTTP

协议是标准 JSON-RPC 2.0 over HTTP POST。不用任何 SDK：

# 1) 握手
curl -s -X POST "http://127.0.0.1:47321/mcp?token=你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"my-agent","version":"1.0"}}}'

# 2) 看有哪些工具
curl -s -X POST "http://127.0.0.1:47321/mcp?token=你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'

# 3) 调一个工具
curl -s -X POST "http://127.0.0.1:47321/mcp?token=你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"bank_stats","arguments":{}}}'

Python 版：

import json, urllib.request

URL = "http://127.0.0.1:47321/mcp?token=你的令牌"
_id = 0

def rpc(method, params=None):
    global _id
    _id += 1
    body = {"jsonrpc": "2.0", "id": _id, "method": method}
    if params is not None:
        body["params"] = params
    req = urllib.request.Request(
        URL, data=json.dumps(body).encode(),
        headers={"Content-Type": "application/json"},
    )
    with urllib.request.urlopen(req, timeout=40) as r:
        return json.loads(r.read())

rpc("initialize", {"protocolVersion": "2025-06-18", "capabilities": {},
                   "clientInfo": {"name": "demo", "version": "1"}})
print(rpc("tools/list")["result"]["tools"][0]["name"])

res = rpc("tools/call", {"name": "bank_search",
                         "arguments": {"points": ["二次函数"], "limit": 5}})
print(res["result"]["content"][0]["text"])

Node 版：

const URL = "http://127.0.0.1:47321/mcp?token=你的令牌";
let id = 0;

async function rpc(method, params) {
  const body = { jsonrpc: "2.0", id: ++id, method };
  if (params !== undefined) body.params = params;
  const res = await fetch(URL, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  });
  return res.json();
}

await rpc("initialize", { protocolVersion: "2025-06-18", capabilities: {},
                          clientInfo: { name: "demo", version: "1" } });
const tools = await rpc("tools/list");
console.log(tools.result.tools.length, "个工具");

注意 initialize 之后按规范客户端应发一条 notifications/initialized 通知。备题达不做强制校验，但严格的框架可能会要求，发一下更保险。

五、能拿它做什么：4 个真实场景

场景 1：让 AI 出一套卷子

你：用 petita 帮我组一套「二次函数」的单元卷，选择题 10 道、填空题 5 道，
    难度以中为主，把选好的题放进组卷篮。

AI：（调 bank_search 三次，分别检索三种题型）
    （调 cart_add 把 15 道题放进去）
    已经放进去了 15 道，共 75 分。你在备题达里点「组卷」就能导出。

场景 2：查漏补缺

你：我们班「文言虚词」这块一直考不好，帮我看看题库里这个考点有多少题、难度分布怎样。

AI：（调 points_list 查「文言虚词」）
    （调 bank_search 带 lesson 过滤）
    题库里「文言虚词」共 23 道，其中易 8 道、中 11 道、难 4 道。
    难度的梯度是够的，但题目集中在《劝学》《师说》两篇，
    其他篇目几乎没有——建议补充。

场景 3：批量整理背诵卡

你：把《赤壁赋》里的名句做成背诵卡片，正面给上句，背面给下句，放到「必背原文」分类。

AI：（调 memory_add 12 次）
    做了 12 张。你在「记忆」模块能看到，可以直接开始自测。

场景 4：排复习计划

你：下周有期中考试，帮我看看校历这周还有什么安排，然后排一下复习重点。

AI：（调 calendar_get 拿到本周日程）
    （调 progress_get 看进度）
    这周三有调课、周五下午有一节课空着。按进度你现在到第三单元，
    建议把「二次函数图像」和「根与系数关系」放在周四……

六、安全说明（重要）

6.1 数据不出本机

MCP 监听的是 127.0.0.1，只有本机能连，公网访问不到。备题达本身不往任何服务器发数据。

但要说清楚：你调的 AI 客户端会把工具返回的内容发给他自己的模型。如果那个模型在云端（Claude、GPT），题目内容就上了云。想完全不出去，就用本地模型（Ollama / LM Studio）。

6.2 令牌是干什么的

你电脑上任何程序都能连 127.0.0.1:47321。令牌的作用是让没拿到令牌的程序调不动。

  • 令牌在首次启动时随机生成，存 %LOCALAPPDATA%\top.inkstain.petita.general\config\mcp.json
  • 泄露了就点设置里的「重新生成」，旧的立刻失效
  • 别把带令牌的地址贴到公开的地方（论坛、GitHub issue）

6.3 写操作的边界

  • 关着开关时：AI 只能提案，必须你点「执行」
  • 打开开关时：AI 直接写，但每次写都留撤销记录，Ctrl+Z 能回退
  • 没有任何工具能删除数据：cart_remove 只从组卷篮里移除（题目本身还在），其他工具只增不减
  • 没有任何文件、命令、网络类工具：AI 碰不到你的磁盘和终端

6.4 应用关了就断了

MCP 不是常驻服务。关掉备题达，端口就没了，AI 会收到「请先打开备题达」。这是设计如此——数据在应用里，应用不在就没有数据可给。

七、排错

7.1 连不上

先自查这三条：

# 1) 应用开着吗？服务在跑吗？
curl http://127.0.0.1:47321/health

正常返回：

{"ok":true,"app":"petita","running":true,"page_alive":true,"tool_count":23,"auth_required":true}
  • running: false → 端口没起来。看设置页是不是显示「未运行」
  • page_alive: false → 应用开着但页面没加载完，等两秒再试
  • 连 curl 都失败 → 端口被占或应用没开
# 2) 令牌对不对？
curl -X POST "http://127.0.0.1:47321/mcp?token=你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

返回 401 → 令牌错了，去设置页重新复制。

# 3) 工具调得通吗？
curl -X POST "http://127.0.0.1:47321/mcp?token=你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"profile_get","arguments":{}}}'

如果被别的程序占了，改用别的端口：设置 → MCP → 端口，改完重启应用。

八、常见问题

Q：MCP 要不要额外付费？ 不要。用的是你 AI 客户端自己的额度。备题达这边不收钱、不联网。

Q：能不能同时接好几个客户端？ 能。多个客户端可以同时连同一个端口，互不影响。

Q：网页版（双击 index.html）能用吗？ 不能。网页版没有进程权限，起不了本地服务。只有桌面版支持。

Q：语文线和通用线能同时开吗？ 能，但端口会冲突。后开的那个会自动换端口，以各自设置页显示的为准。

Q：换电脑了要重新配吗？ 要。令牌是每台机器独立生成的。

Q：AI 会不会把我的题库删了？ 不会。没有删除工具。cart_remove 只动组卷篮，不动题库。

Q：能读我的教案全文吗？ lesson_get 和 guide_list 会返回篇目、要点、目标等结构，但不返回整篇教参正文——只给摘要级别的信息，避免整库内容一次性流出去。

Q：怎么关掉 MCP？ 设置 → MCP → 关闭开关。或者直接把应用退了。

项 值
协议 JSON-RPC 2.0 over HTTP POST
端点 POST /mcp
传输 streamable-http 的请求/响应模式（不做 SSE 流）
